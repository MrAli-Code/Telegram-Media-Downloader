# عیب‌یابی — Telegram Downloader

راهنمای رفع مشکلات رایج.

## ۱. برنامه اجرا نمی‌شود یا هنگام شروع بسته می‌شود

1. لاگ‌ها را بررسی کنید:
   ```
   %LOCALAPPDATA%\TelegramDownloader\logs
   ```
   جدیدترین فایل `.log` را باز کنید.
2. اولین خط‌های Exception را برای پشتیبانی بفرستید.
3. اگر پوشه دانلود یا پوشه داده قابل نوشتن نیست، آن را در تنظیمات عوض کنید:
   **تنظیمات ← مسیر ذخیره**.

راه‌حل موقت نشست خراب: حساب را از **تنظیمات ← حساب‌های تلگرام ← حذف حساب** خارج و دوباره وارد شوید.

## ۲. «برای دانلود ابتدا باید به حساب تلگرام وارد شوید.»

- از **تنظیمات ← نشست/وضعیت نشست** وضعیت را بررسی کنید.
- اگر نشست منقضی شده: **حذف حساب** سپس **افزودن حساب** و ورود مجدد.
- اگر از چندین دستگاه استفاده می‌کنید و نشست در دستگاه دیگر بسته شده، تلگرام این نشست را Invalid می‌کند؛ دوباره وارد شوید.

## ۳. FloodWait: «تلگرام از ما خواسته n ثانیه صبر کنیم.»

- این رفتار طبیعی API تلگرام در دانلودهای پشت‌سرهم است.
- برنامه زمان انتظار را نمایش می‌دهد، صبر می‌کند و خودکار ادامه می‌دهد.
- برای کاهش FloodWait: تعداد دانلود هم‌زمان را در **تنظیمات ← اجرای همزمان** کم کنید، یا بین دانلودهای بزرگ وقفه بیندازید.

## ۴. لینک در صف اضافه نمی‌شود (پیام «تکرار» / «قبلاً در صف است»)

- اگر همان فایل/لینک هنوز در صف است، افزوده نمی‌شود.
- از صفحه **فایل منیجر** یا **فضاهای من** دانلود را مدیریت کنید، یا صف را خالی کنید: دکمه **توقف همه** را بزنید و موارد را از منوی کارت حذف کنید.

## ۵. دانلود ناتمام / فایل `.part` باقی مانده

- دانلودها ابتدا با پسوند `.part` نوشته می‌شوند تا فایل ناقص به‌عنوان سالم RSS نشود.
- اگر برنامه در حین دانلود بسته/کرش شود، در اجرای بعدی:
  «دانلودهای ناتمام پیدا شد» نمایش داده می‌شود و (با گزینه «ادامه همه») از همان Offset ادامه می‌یابد.
- اگر فایل `.part` اضافه دیدید، می‌توانید با خیال راحت آن را از پوشه دانلود حذف کنید (دانلود بعدی از ابتدا انجام می‌شود).

## ۶. شمارشگر Storage/Dashboard نامعمول است

- Dashboard از اندیس محلی (SQLite) محاسبه می‌شود؛ اگر فایلی دستی پاک شده، **همگام‌سازی** کنید تا اندیس به‌روز شود.
- حجم ‹دانلود کل› فایل‌های موفق را نشان می‌دهد؛ فایل‌های تکراری (Keep Both) جداگانه شمارش می‌شوند.

## ۷. دانلود تکراری / «فایل مشابه موجود است»

- گزینه‌های پیشنهادی: **Skip / Replace / Rename / Keep Both**.
- با فعال بودن SHA-256، تشخیص حقیقی بر اساس Hash انجام می‌شود.
- اگر می‌خواهید فایل جایگزین شود، گزینه **Replace** را انتخاب کنید؛ در غیر این صورت نسخه قبلی حفظ می‌شود.

## ۸. جستجو سریع نیست

- جستجو بر اساس اندیس محلی (SQLite) انجام می‌شود؛ برای هزاران فایل مشکلی نیست.
- اگر فایل تازه Sync شده در نتایج نیست، **همگام‌سازی** را اجرا کنید.

## ۹. پروکسی وصل نمی‌شود

- از **تنظیمات ← پروکسی** نوع (SOCKS5/HTTP)، میزبان و پورت را وارد کنید؛ MTProto Proxy در تلگرام نیاز به `Secret` دارد.
- برای پروکسی HTTP معمولی، `Secret` را خالی بگذارید.

## ۱۰. SmartScreen / آنتی‌ویروس هشدار می‌دهد

- برنامه امضای دیجیتال ندارد؛ ویندوز برای فایل‌های بدون امضا هشدار می‌دهد.
- روی **More info → Run anyway** بزنید یا اگر آنتی‌ویروس فایل را حذف کرد، исключение اضافه کنید؛ فایل را از سورس بازبینی کنید.
