# Telegram Downloader — Telegram File Manager

نرم‌افزار دسکتاپ ویندوز (PySide6) برای دانلود، مدیریت و سازمان‌دهی فایل‌های قابل‌دسترس حساب تلگرام.

**نسخه:** 1.0.1 — **توسعه‌دهنده:** علی خان‌محمدی | [alikhanmohammadi.ir](https://alikhanmohammadi.ir/)

---

## معرفی

این برنامه از یک دانلودر ساده به یک **Personal Telegram Cloud / File Manager** ارتقا یافته است و شامل بخش‌های زیر است:

- **صف دانلود** — دانلود موازی، توقف/ادامه، تلاش مجدد، اولویت (کم/عادی/بالا)، جابجایی به ابتدای صف
- **مدیریت فایل** — مشاهده، جستجو، مرتب‌سازی، پوشه‌بندی، دلخواه، پنهان، زباله، چندانتخابی، دانلود گروهی، تغییر نام، انتقال، باز کردن فایل/پوشه
- **فضاهای من (Multiple Drives)** — اتصال چند فضای تلگرام (Channel / Group / Saved Messages) با اندیس و تنظیمات مستقل
- **همگام‌سازی** — همگام‌سازی دستی یا خودکار (5/15/30/60 دقیقه یا دستی) با نگهداری Sync Cursor (افزایشی)
- **تاریخچه** — ثبت کامل دانلودها با وضعیت، منبع و مسیر
- **داشبورد** — وضعیت تلگرام، دانلودهای فعال، در انتظار، کامل/ناموفق، حجم کل، فایل‌های اخیر، فضاهای ذخیره‌سازی
- **تنظیمات** — مسیر ذخیره، هم‌زمانی، ارتفاع سرعت، پروکسی، چند حساب، ظاهر (پوسته/فونت/RTL)، زمان‌بندی دانلود، بروزرسانی و مدیریت نشست
- **عملکردهای پس از اتمام** — خروج / Shutdown / Restart / Sleep / Hibernate با شمارش معکوس و لغو
- **System Tray** — توقف/ادامه همگانی، چسبیدن به سینی، اعلان‌ها
- **بروزرسانی** — بررسی نسخه جدید از GitHub Releases یا سرور قابل تنظیم

## نسخه‌ها

| نسخه | فایل | اعتبارنامه API |
|---|---|---|
| Personal | `TelegramDownloader-Personal.exe` / `-Setup.exe` | از پیش تعبیه‌شده (Build-Secret) |
| Public | `TelegramDownloader-Public.exe` / `-Setup.exe` | کاربر در اولین اجرا از `my.telegram.org` وارد می‌کند |

## سیستم موردنیاز

- ویندوز 10/11 (x64)
- اتصال اینترنت (پایدار برای دانلودهای بزرگ)
- حداقل 2GB RAM؛ مصرف حافظه برای فایل‌های بزرگ ثابت می‌ماند (Streaming/Chunked)

## ذخیره‌سازی داده‌ها

| داده | مسیر |
|---|---|
| تنظیمات، اندیس SQLite، صف، حساب‌ها، نشست | `%APPDATA%\TelegramDownloader` |
| لاگ‌ها | `%LOCALAPPDATA%\TelegramDownloader\logs` |
| پوشه دانلود پیش‌فرض | `%USERPROFILE%\Downloads\TelegramDownloader` |

## میان‌برها

- `Ctrl+F` — جستجو در فایل‌ها
- `Ctrl+V` — پیست لینک در فیلد افزودن
- `Ctrl+Enter` — افزودن لینک به صف
- `Ctrl+Shift+V` — افزودن لینک کلیپ‌بورد مستقیم به صف

## ساخت از سورس

پیش‌نیازها: Python 3.12، PySide6، Telethon؛ سپس:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py            # اجرا (نسخه پیش‌فرض توسعه: Personal)
```

تست:

```powershell
pytest
ruff check .
```

## بازسازی Release (هر دو نسخه)

```powershell
.\build_personal.bat
.\build_public.bat
```

خروجی‌ها در `release\Personal` و `release\Public` (فایل اجرایی یک‌فایله + نصب‌کننده Inno Setup). سمت اختیاری `-Clean`:

```powershell
.\build_personal.bat -Clean
```

## مجوز و اعتبار

- پروژه مستقل از TeleDrive است؛ تنها ایده‌های عمومی/معماری اقتباس شده و پیاده‌سازی بازنویسی شده است. جزئیات در `SECURITY-fa.md` و بخش «سازگاری مجوز» سند گزارش نهایی.
- وابستگی‌ها: **PySide6** (LGPL-3.0)، **Telethon** (MIT)، **PyInstaller** (GPL-2.0-or-later — فقط برای ساخت)، **Inno Setup** (نصب‌کننده، جدا از برنامه).
- برنامه فقط به محتوایی دسترسی دارد که خود کاربر به آن دسترسی قانونی دارد و هیچ ابزار دور زدن محدودیت تلگرام ارائه نمی‌دهد.
